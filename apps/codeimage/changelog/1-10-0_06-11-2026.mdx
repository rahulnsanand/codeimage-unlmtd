# v1.10.0

<mdxComponents.h3>📁 Import Code from File</mdxComponents.h3>

You can now import your code files directly into the editor instead of copy-pasting!

- **Drag & Drop or Click to Upload**: Open the import dialog, then drag a file or select it from your device.
- **Automatic Setup**: The editor automatically detects the language from the file extension, adjusts the editor's highlighting mode, and formats the code for you.
- **Browser-Only Processing**: Reassuringly, *your code files never leave your browser* — they are processed completely client-side.

<mdxComponents.h3>🐳 Host Locally with Docker</mdxComponents.h3>

You can now containerize and run CodeImage UNLMTD on any of your own servers!

- **Universal Support**: Native multi-architecture images work seamlessly on Windows, macOS, Linux, and Raspberry Pi (ARM64).
- **Super Light**: Fast startups and a runtime footprint of less than 10MB RAM.
